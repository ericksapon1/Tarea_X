Organizador de Ranking Académico

Este es un pequeño pero poderoso sistema diseñado para organizar a los estudiantes según sus calificaciones de forma rápida y automática. 

Este módulo está preparado para integrarse como una pieza clave dentro de un proyecto escolar más grande.

¿Cómo funciona y por qué es tan útil?

Imagina que tienes una estantería enorme y te van entregando miles de expedientes de estudiantes que debes acomodar por su nota (de mayor a menor). 

Si usaras un **sistema normal**, los expedientes se irían apilando hacia un solo lado formando una fila larguísima. Si luego quisieras buscar a un alumno en específico, tendrías que caminar revisando esa fila uno por uno, perdiendo muchísimo tiempo.

Para solucionar esto, construimos un **Organizador Inteligente** (que en programación llamamos *Árbol AVL*).

La magia de nuestro sistema

* **Se auto-equilibra:** Cada vez que ingresamos a un estudiante nuevo, el sistema vigila que nuestra estantería no se desbalancee. Si nota que un lado tiene muchos más expedientes que el otro, los reacomoda automáticamente para mantener una forma perfecta de pirámide.
* **Búsquedas ultra rápidas:** Como la estantería siempre está perfectamente ordenada y equilibrada, podemos tomar "atajos" para encontrar cualquier calificación en fracciones de segundo, sin importar si hay 100 o 10,000 estudiantes.
* **Desempate justo:** Si dos estudiantes sacan exactamente la misma nota, el sistema usa su número de carnet (ID) para acomodarlos, evitando confusiones.

¿Qué puedes hacer en este sistema?

1. **Agregar alumnos:** Ingresa los datos del estudiante y su calificación; el sistema le buscará su lugar ideal automáticamente.
2. **Ver el Ranking (Top):** Muestra la lista de todos los estudiantes ordenados del mejor puntaje al más bajo.
3. **Buscar al instante:** Escribe una calificación y el sistema te dirá exactamente a quién le pertenece al momento.
4. **Ver estadísticas:** Un pequeño monitor que te avisa cuántos estudiantes hay y te comprueba que la "estantería" sigue perfectamente equilibrada.
